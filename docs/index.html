1설치 순서

  1. 위의 설치 파일 내려받기 버튼을 클릭합니다.
  2. 브라우저가 차단하면 “계속” 또는 “유지”를 눌러 내려받기를 허용합니다.
  3. 내려받은 SparkleMacro_Setup_v1.0.17.exe 파일을 마우스 오른쪽 버튼 → 관리자 권한으로 실행합니다.
  4. “Windows의 PC 보호” 경고가 뜨면 추가 정보 → 실행을 선택합니다.
  5. 설치 화면의 안내에 따라 다음을 눌러 설치를 마칩니다.
  6. 바탕 화면의 스파클 매크로 아이콘으로 실행합니다.

  • 설치 후에는 실행할 때마다 새 버전을 자동으로 확인합니다. 새 버전이 있으면 안내 창이 뜨고 바로 적용할 수 있습니다.
  • 이미 예전 버전을 쓰고 계신 분도 이 설치 파일로 덮어쓰기 설치하면 최신 버전으로 맞춰집니다.
  • 설치 중 백신 프로그램이 경고를 띄우면 허용을 선택해 주세요.
설치 파일은 반드시 이 페이지의 버튼으로만 내려받으세요. 출처가 불분명한 파일은 실행하지 마세요.
